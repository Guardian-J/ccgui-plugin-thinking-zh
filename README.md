# 中文思考（thinking-zh）

CC GUI 插件：强制模型在 **thinking / reasoning 通道**使用中文。只约束内部推理，不改变最终回复语言；代码、命令、路径、标识符保持原文。

Tier-1 单文件 ESM 插件（`main.js`），无构建步骤、无依赖。

## 解决什么问题

模型的思考过程默认跟随会话语言，用中文提问也常常得到英文思考。把「思考语言」写进可见对话只会污染历史；事后翻译也不可行——宿主的思考区按纯文本渲染，插件事件流里没有思考增量，SDK 也不暴露会话消息内容。因此插件走宿主受支持的通道：**在每一轮请求尾部的内部段注入一条隐藏指令**。

## 工作原理

1. **请求尾部注入**：`beforeTurn` 钩子返回一条 `promptContribution`（`placement: system-tail`、`visibility: internal`），宿主自动隐藏这段文本，不进入可见对话；关闭开关后宿主会补发一次撤回通知。
2. **系统级注入（Claude / GPT 必需）**：宿主把所有贡献一律拼进 user 消息，Claude 会把它当成提示注入而拒绝服从（实测原话：「我无法控制内部推理的呈现格式」）。唯一不改宿主代码的做法是写引擎自己的全局记忆文件——它们进入系统提示：
   - `~/.omp/agent/AGENTS.md`
   - `~/.claude/CLAUDE.md`
   - `~/.codex/AGENTS.md`

   插件用 `<!-- thinking-zh:begin -->` / `<!-- thinking-zh:end -->` 标记段维护这些文件：目标不存在时创建，关闭开关或停用插件即移除标记段；启动时会补写一次，文件被外部删除也能恢复。该操作通过 `plugin_exec_run` 调 `node -e` 完成，写入采用临时文件 + rename。
3. **状态栏与命令**：状态栏徽章一键开关；命令面板提供「中文思考：关闭 / 开启」与「中文思考：打开设置」。

## 功能

- 每轮自动注入中文思考指令；思考语言可选 **简体中文** / **繁體中文**
- 可追加自定义要求（最多 2000 字），例如「数学推导保留公式符号」
- 注入范围：**整个会话**（宿主记住，后续轮次自动携带）或 **仅当前轮**
- 系统级注入开关 + 「立即同步」按钮，状态显示已同步文件数与写入结果
- 注入内容预览，以及宿主确认注入的次数与时间
- 设置即时保存，下一轮发送生效；「恢复默认」一键重置

## 安装

1. 打开 CC GUI 侧边栏「插件」→「从本地目录安装」。
2. 选择包含 `manifest.json` 的本目录。
3. 到设置页的「中文思考」分区调整选项。

安装会复制整棵目录（跳过 `node_modules` 与 `.git`）。修改代码后重新走一次「从本地目录安装」即可热重载，无需重启应用。

## 权限

| 权限 | 用途 |
| --- | --- |
| `prompt.contribute.internal` | 每轮注入隐藏的中文思考指令 |
| `ui:settings-section` | 设置页「中文思考」分区 |
| `ui:status-bar` | 状态栏开关徽章 |
| `ui:command` | 命令面板命令 |
| `storage` | 保存插件设置 |
| `exec:node` | 调用 `node -e` 维护引擎全局记忆文件中的标记段 |

## 兼容性

- 插件 `tier: js`，`sdkVersion: ^0.3`。
- DeepSeek 等服从尾部指令的模型：关闭系统级注入即可。
- Claude / GPT：必须开启「系统级注入」，否则通常不会服从。

## 目录结构

```text
.
├── manifest.json   # 插件元数据与权限声明
├── main.js         # 全部逻辑：注入钩子、系统级同步、设置页、状态栏、命令
└── .gitignore
```

## 开发约束

- `main.js` 必须自包含：不能有任何 `import`，不能使用 JSX；组件用 `ctx.react.createElement` 构建。
- 每个订阅、定时器都要有清理；`activate` 返回清理函数。
- 只声明真正用到的权限；调用未声明的能力会抛错。
